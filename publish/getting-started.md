# Getting started

This site is generated from the vault's `publish/` folder.

## Add a page

Create a Markdown file in `publish/`.

Example:

```md
---
sidebar_position: 10
---

# My page

Hello from Obsidian.
```

## Organize pages

- use folders for sections
- use `sidebar_position` to sort pages
- keep private notes out of `publish/`
